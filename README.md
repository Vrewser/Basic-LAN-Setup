# Basic LAN Setup
A step-by-step process of how I make a basic LAN setup. Using Cisco Packet Tracer.

## Place an ISR4331 Router
* Inside the network devices, into the routers, choose the one labeled "4331" and place it down.
<img width="482" height="446" alt="router" src="https://github.com/user-attachments/assets/83352dcc-f5a6-4efe-a34c-ded62671efeb" />

## Place a Switch below the router
* Just a bit further below from the router, place down a switch labeled "2950-24".
<img width="486" height="457" alt="switch" src="https://github.com/user-attachments/assets/aaad279d-404f-4f3d-8a02-e3aff81ce5af" />

## Place down PCs
* Place down 3 PCs below the switch.
<img width="485" height="459" alt="PCs" src="https://github.com/user-attachments/assets/074c6927-b8b8-46de-8fa3-c02754ac9e1e" />

## Connect the Router to the Switch
* Head to the connections area in the options, then press the one labeled "Straight-through cable" or the solid white line.
* From the router, pick GigabitEthernet 0/0/0.
* To the switch, pick FastEthernet 0/1.
